## 数据口径

- 信息获取时间：2026-10-08（北京时间）
- 评分：10 分制主观共识分，综合官方价目透明度（是否公开续费价）、续费是否加价、whois 隐私是否免费、控制台与 API 完整度、转入转出便利性及用户社区口碑；跨类型（云平台 / 老牌注册商 / 交易平台 / 平价型）不宜直接横向比较
- 价格：国内人民币；海外 USD 原值并按 1 USD≈7.1 CNY 约合（欧元档先按 €1≈$1.08 折美元再换算，量级参考）；重点后缀覆盖 .com / .cn / .ai / .io / .dev 等
- 免费额度与价格为官方口径，无法核实一律标"待确认"
- 关注维度：首年价与续费价的落差（价格陷阱）、whois 隐私是否免费、转入转出限制（转移码 / 60 天锁定 / 备案联动）、管理面板与 API、实名与 ICP 备案联动

## 快速结论

- 国内第一梯队：阿里云万网（9.0）、腾讯云 DNSPod（8.9）、西部数码（8.4）、华为云（8.3）、新网（8.2）
- 海外第一梯队：Cloudflare Registrar（9.0）、Porkbun（8.8）、Namecheap（8.4）、Spaceship（8.3）、Squarespace Domains（8.2）
- 核心价格结论：同一个 .com，续费年费从约 ¥74（Cloudflare 按成本）到约 ¥272（Gandi），差价约 3.7 倍；「首年低价、续费翻倍」是国内与海外共通的定价模式，应看多年持有成本而非首年数字
- .ai / .io / .dev 是当前价格风险集中区：.ai 注册价最低档即约 ¥461（Spaceship）～¥554（Porkbun）且续费同档；Dynadot 的 .io 从 $28.89 涨到续费 $53.50
- 国内已出现官方调价证据：腾讯云 2026-08-25 对 .xyz、.online、.site 等 70 余个后缀同步上调；阿里云自 2026-10-07 起把 .studio 调至 ¥328/年、.gold 调至 ¥698/年

## 重要纠错（已核验）

- **Google Domains 已停服**：2024 年 7 月完成客户迁移，域名业务并入 Squarespace，domains.google 不再是独立注册商
- **Freenom 已停服**：免费 .tk/.ml/.ga/.cf/.gq 长期停止注册与解析，官网仅剩公告页，已列入排除清单
- **Cloudflare Registrar 能力已澄清**：现已支持新注册（不只是转入），但要求域名解析必须托管在 Cloudflare
- **万网（hichina.com）与阿里云万网（wanwang.aliyun.com）是同一主体的双入口**，不是两家注册商，不作重复计数
- **「新网互联」（dns.com.cn）与「新网数码」（xinnet.com）主体不同**，比价与维权前需核对 WHOIS 中的 Registrar 名称与 ICANN 认证名录
- **Verisign、CNNIC、ICANN、IANA 不是零售注册商**（注册局 / 管理机构 / 根区数据库），列入核验表而非主表
- **Sedo / Afternic 是二级交易平台**（无注册与解析资质、佣金制），与注册商不可放在同一价格轴比较
- 以「域名到期 / 续费」「中文域名保护」名义施压付款的第三方通知与仿冒页面，一律不视为官方来源，已列入排除清单
