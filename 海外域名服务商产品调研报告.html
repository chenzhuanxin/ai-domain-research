01核心结论

海外域名市场已经分成互不重叠的四条线：以 Cloudflare 为代表的「按成本转售」（注册价＝续费价）、以 Porkbun / Spaceship / Dynadot / NameSilo 为代表的「平价扁平定价」、以 GoDaddy / Network Solutions / Gandi 为代表的「首年低价、续费翻倍」老牌注册商，以及只做成交抽佣的二级交易平台（Sedo / Afternic）。同一个 .com，续费价从约 $10.44 一路到 $38.38，差价接近四倍。

续费价才是真实价格，首年价基本是营销

把 .com 放到同一把尺子上：Cloudflare 按注册局成本约 $10.44–10.46、Spaceship $9.98、Dynadot $10.88、Porkbun $11.08，而 GoDaddy 续费 $22.99、IONOS $20.00、Network Solutions $22.99、Gandi $38.38——首年促销却常低至 $0.99–5。判断标准很简单：把「首年价 ×1 + 续费价 ×N」算成多年持有成本，本报告因此在价格列同时给出注册与续费两个数。

免费 whois 隐私已成平价注册商标配，老牌反而收钱

Cloudflare、Porkbun、Spaceship、Dynadot、NameSilo、Hover、Gandi 把域名隐私保护做成默认免费项，OVHcloud 更把隐私保护默认开启；而 Network Solutions、Name.com 仍把隐私作为付费附加（口径见待确认）。隐私收费与否，在长期持有下每年要多付 $8–15，比首年省下来的钱更值得计算。

.ai / .io / .dev 是新价格风险集中区

第三方比价（2026-10-07）显示 .ai 注册价最低档即约 ¥461（Spaceship）、Porkbun ¥554，续费同档位；Dynadot 的 .io 从 $28.89 涨到续费 $53.50、.co 从 $15.50 到 $31.20、.xyz 从 $1.99 到 $14.45。ccTLD 与热门新后缀的注册局定价权不在注册商手里，选后缀前先看注册局规则与历史调价记录。

.com 续费年费与质量评分的关系

横轴为该服务商的 .com 续费年费（元/年，海外原价按 1 USD≈7.1 CNY 换算），纵轴为综合评分。此处刻意用「续费价」而非首年促销价，因为它才代表长期持有成本。

虚线为 .com 注册局按成本基准线（注册局 $10.26 + ICANN $0.20 ≈ $10.46，约 ¥74）。仅纳入 .com 定价口径明确的服务商；Netim（价格待确认）、Sedo 与 Afternic（佣金制，无注册价）未纳入，原因见待确认清单。

把续费价与评分放在一起，规律比国内更清楚：横轴左侧（¥70–125）几乎被平价型与云平台型占满——Cloudflare ¥74、Spaceship ¥71、Dynadot ¥77、Porkbun ¥79、OVHcloud ¥104、Namecheap ¥106、NameSilo ¥123——而右侧（¥135–272）集中了 Hover、Gandi、GoDaddy、Network Solutions、Name.com 等老牌，其中 Gandi（¥272）与 Cloudflare（¥74）之间是 3.7 倍的差距。预算敏感的组合持有应当把「续费价 + 隐私是否免费」作为第一筛选条件，把品牌与客服作为第二筛选条件。

052024—2026 关键节点

按公开可查的并购、政策与调价时点排列，用于理解海外价格结构是怎么形成的。

两年之内发生了三件事：海外注册商格局收敛（Google Domains 并入 Squarespace，四强主导）；后缀供给即将再次扩容（ICANN 推进新一轮 new gTLD）；而定价权持续向注册局集中——注册局上调批发价，注册商要么按成本转嫁（Cloudflare、Dynadot、Spaceship 一类），要么把涨幅藏进续费价（GoDaddy、IONOS、Gandi 一类）。选注册商的本质，是选它站在哪一边。
